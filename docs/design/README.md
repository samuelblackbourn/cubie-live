items → assets → art system. The decisions table is the index; every later addendum

## A note on names

These notes name the creator because they are working documents. Everything
*public* — the site, the diary, the About window, the store, the stream — uses
"the creator" and never a name (decision 35). The automod enforces it; this folder
does not need to.
